# Hi I'm Jiyoung 👋

사용자의 입장에서 생각하고, 필요한 기능을 구현하는 웹 개발자입니다.

Java와 Spring Boot를 중심으로 웹 개발을 공부하며,
개인·팀 프로젝트를 통해 기능 구현부터 코드 개선, 배포까지 경험하고 있습니다.

## 💻 프로젝트

### MOBILIA | 가구 쇼핑몰(팀 프로젝트)
Spring Boot 기반 가구 쇼핑몰 웹 서비스로, 5인 팀 프로젝트에서 팀장을 담당했습니다.

#### 담당 기능
- 메인 페이지 UI 구현
- 전체상품·브랜드별·공간별 상품 목록 페이지 구현
- 카테고리별 상품 조회 및 정렬 기능 구현

#### 코드 개선 및 협업
- 팀원 코드 검토 및 개선 방향 공유
- 역할 분담, 진행 상황 관리 및 프로젝트 통합

[GitHub](https://github.com/Jiyoung100/mobilia-furniture-shop) ·
[서비스](https://themobilia.shop/)

### DanceTalk | 댄스 커뮤니티(개인 프로젝트)
교육과정에서 실습한 Q&A 게시판을 기반으로, 댄스 관련 정보를 공유하는 커뮤니티로 확장한 프로젝트입니다.

#### 주요 기능
- 회원가입·로그인 및 게시글·답변·추천 기능
- 카테고리별 게시글 조회 및 검색·페이징

#### 추가 기능 및 배포
- 게시글 카테고리 기능 추가
- AWS Lightsail 배포 및 도메인·HTTPS 연결

[GitHub](https://github.com/Jiyoung100/dancetalk) ·
[서비스](https://jiyoungdev.cloud/)
